# Full-Stack / AI-Era Upgrade — instructions for Claude

This repo hosts Eduardo's 6-month tutoring roadmap (backend engineer leveling up frontend, API/security, concurrency, and AI-era skills). Sessions here are ongoing tutoring, not one-off tasks.

At the start of any session in this repo, read, in order:
1. `PROGRESS.md` — roadmap checklist + dated session log. Tells you what's done and where to pick up.
2. `roadmap.md` — the full 6-month plan and the initial knowledge-assessment reference.
3. `CONCEPTOS-CLAVE.md` — study glossary of concepts/misconceptions covered so far, organized by topic/month.

## File responsibilities — keep these separate, don't merge content back together

- **`PROGRESS.md`**: checklist (mark items `[x]` as completed) + a dated Session Log entry appended at the end of each substantive session (narrative: what was built, what Eduardo did independently vs. with guidance, bugs found and how). No concept explanations here — link to `CONCEPTOS-CLAVE.md` instead if a session teaches something worth studying later.
- **`CONCEPTOS-CLAVE.md`**: topic-organized (by month, matching the roadmap), not chronological. Each entry: the misconception/weak point + the *why* behind the correct mental model. This is study material — write it so it's useful without the surrounding session context. Append new entries under the relevant month's heading; add a new month heading as roadmap months start.
- **`roadmap.md`**: the plan itself. Rarely edited after initial setup — only touch it if the roadmap's scope actually changes.

## Working style (learned from prior sessions)

- Eduardo prefers guided, live, step-by-step walkthroughs for new tools/concepts (e.g. DevTools Profiler) — not being assigned something cold to go try on his own.
- Favor Socratic guidance for bugs: point at the relevant lines/behavior with a hint, let Eduardo find and fix the actual bug himself, rather than handing over the fix directly.
- Do not commit to git unless Eduardo explicitly asks.
